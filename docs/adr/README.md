## Structure of an ADR
Each record follows Michael Nygard's format:
1. **Title**: Number and descriptive decision name.
2. **Status**: Proposed, Accepted, Deprecated, or Superseded.
3. **Context**: The engineering or UX problem being solved.
4. **Decision**: The chosen technical standard or architectural approach.
5. **Consequences**: The positive outcomes and accepted trade-offs.
